# AST1040 A0 Prebuilt Binaries

This folder contains prebuilt firmware specifically for ASPEED AST1040 A0 silicon.

- **caliptra-fw.bin**
  - **Description**: Caliptra FMC/Runtime firmware.

- **ast1040_xip_rom_vf402_f1a1817.bin**
  - **Description**: Boot MCU XIP ROM.
